# AR Banking Application

A secure banking backend application built using Spring Boot and MySQL.

## Features

* User Account Creation
* Credit Transaction
* Debit Transaction
* Fund Transfer
* Balance Enquiry
* Name Enquiry
* Transaction History
* PDF Bank Statement Generation
* Email Service Integration
* Swagger API Documentation

## Tech Stack

* Java 17
* Spring Boot
* Spring Data JPA
* MySQL
* Maven
* Swagger/OpenAPI
* iText PDF
* Java Mail Sender

## API Documentation

Swagger UI:
http://localhost:8080/swagger-ui/index.html

## Project Structure

* Controller Layer
* Service Layer
* Repository Layer
* DTOs
* Entity Classes
* Utility Classes

## Database

MySQL database is used to store:

* User details
* Account details
* Transaction history

* PDF statement generation
